玩消费级基因检测原始数据（23andMe、AncestryDNA、WeGene 这些）的人，多半听说过 Admixture算法。Steven Liu 写的 [Admix](https://github.com/stevenliuyi/admix)。它把二十多个经典的群体遗传学祖源计算器打包到了一起，平时拿来跑跑自己的位点很有意思。但它是 Python + SciPy 实现的，想在服务端调用或者塞进容器里，光是带上整套 Python 科学计算环境就很重。

最近我把 [Rootara](/posts/Rootara_v2) 的后端全面切到 Rust，实在不想再为了算一个祖源成分在生产镜像里留着 Python 运行时，干脆顺手把 Admix 用 Rust 重写了一遍，开源在 [AdmixRS](https://github.com/pzweuj/AdmixRS)。

---

## 对齐原版，拿掉环境依赖

AdmixRS 的目标很明确：输入输出和常用参数尽量兼容原版，但运行起来只要一个二进制文件加一份参考模型目录。

- **模型与格式一致**：内置同样的 **27 个活跃参考模型**（涵盖 Dodecad `K7b` / `K12b` / `globe13`、Eurogenes `K13` / `K36`、HarappaWorld、LM Genetics `K47`、E11 等，完整列表见仓库的 [模型说明](https://github.com/pzweuj/AdmixRS/blob/main/data/README.md)），支持 `23andme`（默认）、`ancestry`、`ftdna`、`ftdna2`、`wegene`、`myheritage` 六种常见输入格式，同样保留了 `-z` / `--zhongwen` 中文人群标签输出。
- **零重型依赖**：`Cargo.toml` 里只用了 `clap` 和 `tempfile` 两个轻量 crate，数值拟合自己实现。Windows x86-64、Linux x86-64、macOS（Intel / Apple Silicon）都有现成压缩包，去 [Releases](https://github.com/pzweuj/AdmixRS/releases) 解压就能跑。程序默认读取可执行文件同级 `data/` 下的参考模型，也可以用 `--data-dir` 另指路径。

---

## 怎么读数据和压内存

消费级芯片一次也就几十万行位点，如果把二十多个模型的参考矩阵全常驻内存其实很浪费。

AdmixRS 启动后会先统计这次选定模型用到的所有去重 marker ID，然后只扫一遍输入的基因型文件，只保留命中这些 ID 的分型（常见的纯数字 rsID 直接存成整数键）。等具体跑模型拟合时，每个模型只加载自己匹配到的频率行，算完就释放，哪怕一次连跑全部 27 个模型，内存占用也几乎是一条直线。

似然函数的等位基因方向与上游保持一致（`.alleles` 文件第三列对应 `F`，第二列对应 `1 - F`）。拟合部分使用投影梯度（projected-gradient）求解器在非负且权重和为 1 的约束下最大化对数似然。唯一需要注意的是，AdmixRS 的默认收敛容差（`--tolerance 1e-3`）约束的是剩余总对数似然的改进量，和上游 SciPy 求解器的停机判定略有区别，所以个别比例最后几位小数可能会有一点微调，整体成分和排序是能对齐的。

## 上手跑一把

如果你以前就用过 `admix`，直接把命令里的 `admix` 换成 `admixrs` 就行。不指定 `-f` 时，程序会自动跑自带的 23andMe 公开演示样本。

```bash
# 分析 WeGene 数据，只跑 K7b 和 K36，输出中文人群名、按比例降序并隐藏 <0.01% 的成分
admixrs -f private/sample.txt -v wegene -m K7b K36 -z --sort --ignore-zeros

# 对 23andMe 数据跑完全部 27 个模型，并写出报告文件
admixrs --file private/sample.txt --vendor 23andme --output admixture_results.txt
```

常用参数基本还是那几个：

- `-f` / `--file`：输入基因型文件，省略则运行自带 demo
- `-v` / `--vendor`：指定厂商格式（`23andme`、`ancestry`、`ftdna`、`ftdna2`、`wegene`、`myheritage`）
- `-m` / `--models`：指定要跑的模型名（区分大小写），不传默认全跑
- `-o` / `--output`：把报告同时写进文件（只写 `-o` 默认生成 `admixture_results.txt`）
- `--list-models`：列出所有可用模型

标准输出打各模型的百分比结果，标准错误则会顺带告诉你每个模型实际匹配上了多少个 SNP。
