## 背景

项目接近上线，需要确定合规路线。基因数据平台有两条路：**海内方案**（面向中国用户）或**海外方案**（完全放弃中国市场）。

## 方案对比

| 维度 | 海内方案 | 海外方案 |
|------|----------|----------|
| **目标市场** | 中国用户 | 海外用户（英文界面） |
| **公司主体** | 必须注册中国公司 | 可个人运营或海外公司 |
| **服务器位置** | 中国大陆 | 海外（美国/新加坡等） |
| **支付方式** | 支付宝/微信 | Stripe/PayPal |
| **数据合规** | 等保三级 + 人类遗传资源审批 | GDPR + 当地法规 |
| **核心风险** | 监管严格，合规成本高 | 无限责任（个人运营） |

## 海内方案

### 核心要求

1. **等保三级**：基因数据属于敏感个人信息
2. **人类遗传资源审批**：限时删除模式（7天）可降低风险
3. **个人信息保护法**：单独同意、明示告知、最小必要
4. **医疗器械声明**：仅供科研，不用于临床诊断

### 合规路线

1. **公司注册**（1-2周）：有限责任公司
2. **基础合规**（3-4周）：ICP备案、用户协议、隐私政策
3. **等保测评**（2-3个月）：系统整改、测评备案
4. **持续合规**：年度复测、政策跟踪

## 海外方案

### 核心策略

1. **完全隔离**：ASN封禁中国IP，全英文界面，禁止中国用户
2. **支付限制**：Stripe不支持中国大陆，使用MoR平台或海外公司
3. **数据合规**：遵守GDPR和当地法规，限时删除模式

### 运营模式选择

| 模式 | 成本 | 责任隔离 | 适用场景 |
|------|------|----------|----------|
| **个人运营** | 0元 | ❌ 无 | 试水期，收入低 |
| **美国LLC** | $500-1000/年 | ✅ 有限责任 | 成长期，稳定收入 |
| **香港公司** | 5000-10000港币/年 | ✅ 有限责任 | 亚太市场 |

### 支付方案

- **MoR平台**（Lemon Squeezy、Paddle）：费率5-8%，处理全球税务
- **Stripe**（需海外公司）：费率2.9%，需自行处理税务

### 技术实现

```bash
# ASN封禁中国IP
ipset create china-asn hash:net
while read line; do ipset add china-asn $line; done < ASN.China.list
iptables -I INPUT -m set --match-set china-asn src -j DROP
```

## 风险对比

| 风险类型 | 海内方案 | 海外方案 |
|----------|----------|----------|
| **法律风险** | 监管严格，但合规后稳定 | 个人无限责任，风险高 |
| **税务风险** | 明确，按规申报 | 中国全球征税，CRS透明 |
| **支付风险** | 稳定（支付宝/微信） | 可能被冻结（个人账户） |
| **数据风险** | 等保要求严格 | GDPR罚款高（4%营业额） |

## 建议

### 选择海内方案如果：
- 目标用户在中国
- 愿意投入合规成本
- 需要稳定的商业环境

### 选择海外方案如果：
- 目标用户在海外
- 想快速上线测试
- 接受个人责任风险

### 推荐路径：
1. **短期**：海外个人运营+MoR平台测试市场
2. **中期**：如果收入稳定，注册美国LLC隔离风险
3. **长期**：根据业务方向选择是否进入中国市场

## 总结

两条路各有优劣：
- **海内方案**：合规成本高，但稳定可靠
- **海外方案**：启动成本低，但风险较高

**下一步**：根据目标市场做出选择，开始执行。
